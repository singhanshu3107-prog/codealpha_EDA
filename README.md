**📊 Task 2: Exploratory Data Analysis (EDA) – Spam/Ham Dataset**

Performed Exploratory Data Analysis (EDA) on an SMS Spam/Ham dataset using Python to identify patterns, trends, and data-quality issues.

**Key Activities:**

Analyzed dataset structure, data types, missing values, and duplicate records.

Explored spam vs. ham message distribution.

Created character count, word count, and sentence count features.

Visualized data distributions using histograms, boxplots, pairplots, and correlation heatmaps.

Identified frequent words using word frequency analysis and WordClouds.

Detected potential outliers using the IQR method.

Performed hypothesis testing using the Mann–Whitney U test.

Summarized key insights and data-quality issues.

**Tools & Technologies:**

Python, Pandas, NumPy, Matplotlib, Seaborn, NLTK, SciPy, WordCloud, Jupyter Notebook.

**Objective:** 

To understand the dataset, discover meaningful patterns, validate statistical assumptions, and prepare the data for further analysis and machine learning.
